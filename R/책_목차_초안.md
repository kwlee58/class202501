# 생활 속의 통계학 — 책 목차 초안

> 부제(후보): *교실을 실험실로 — 무작위 배정과 데이터로 배우는 판단과 지각의 과학*

은퇴 후 6학기를 포함해 여러 해 동안 진행한 '생활 속의 통계학' 강의 자료(191개 R Markdown
문서, 매 학기 학생 응답 데이터)를 토대로 한 책의 뼈대.

**관통하는 한 가지 생각:** 통계를 공식으로 가르치지 않고, *학생들 스스로가 실험의
피험자이자 분석가가 되는* 살아있는 실험으로 가르친다. 매주 무작위로 두 집단(Red/Black)으로
나누고, 같은 질문을 다르게 던져 응답을 비교한다. 모든 분석은 R Markdown으로 재현된다.

---

## 여는 글
- 왜 실험으로 통계를 가르치는가
- 강의실이라는 실험실: 한 학기의 흐름
- 은퇴 후에도 강단에 선 이유 — 6학기의 기록

## 1부. 방법 — 교실을 실험실로 만들기
1. 무작위 배정의 힘: Red & Black 게임 *(Red_and_Black 시리즈)*
   - 동전·홀짝으로 처치군과 대조군 만들기
   - "가장 균형 잡힌 배정 찾기" (optimum 탐색)
2. 자료를 모으는 법: 구글 폼, 출석, 명렬 *(Google Forms Attendance, Class Roll)*
3. 재현 가능한 분석: R Markdown으로 쓰는 보고서

## 2부. 지각의 한계 — 보는 것을 믿을 수 있는가
4. 보이지 않는 고릴라: 선택적 주의 *(gorilla 시리즈)*
5. 에임스 방과 착시: 뇌가 만드는 현실
6. 손글씨와 자막 읽기: 맥락이 지각을 바꾼다
7. 변화를 놓치다: 몽키 비즈니스 일루전 (변화맹)

## 3부. 직관의 한계 — 생각의 함정 *(주차별 Quiz 시리즈)*
8. 논리의 함정: 웨이슨 선택 과제 *(Wason Selection Task)*
9. 빨리 vs 깊이: 인지반응검사 *(Cognitive Reflection Test)*
10. 어떻게 묻느냐가 답을 바꾼다: 틀짜기 효과 *(Framing Effects)*
11. 첫 숫자에 끌려가다: 닻내림 효과 *(Anchor Effects)*
12. 가만히 두면 그대로: 기본값 효과 *(Default Effects)*
13. 손실이 더 아프다: 전망이론 *(Prospect Theory)*
14. 한마디 덧붙이면 달라진다: 부연설명의 효과
15. 더 많을수록 좋은가 / 어느 세상에 살겠는가 *(The more the better? / Which World?)*

## 4부. 확률의 역설 — 직관이 배신할 때 *(직관의 한계 / Simulation)*
16. 생일의 우연: 생일 문제 *(Birthday Simulation)*
17. 뒤섞인 편지: 매칭 문제 *(Matching Problem)*
18. 바꿀 것인가 말 것인가: 몬티 홀 문제 *(Monty Hall)*
19. 숫자가 속이다: 연비 환상 (MPG illusion)

## 5부. 나를 측정하다 — 심리 척도로 보는 자신
20. 성격을 숫자로: Big Five 성격검사 *(BFI)*
21. 지능은 하나가 아니다: 다중지능 *(MI)*
22. 나는 얼마나 행복한가: 옥스퍼드 행복 질문지 *(Oxford Happiness)*
23. 먹는 습관을 바꾸다: 조사·계획·비교 *(Food Habits survey/plan/comparison)*

## 6부. 세상을 읽다 — 사회·경제 데이터
24. 세금의 국제 비교: 한국과 OECD *(Tax Korea / Tax OECD)*
25. 경제지표 읽기 *(FRED)*
26. 인구로 보는 사회 *(Demography)*
27. 문해력, 숫자를 읽는 힘 *(Literacy)*
28. 임상시험 결과를 의심하기 *(Clinical Summary)*

## 7부. 한 학기를 데이터로 돌아보기
29. 데이터 실험 종합 *(Data Lab Overview / merged report)*
30. 최종 기록: 성적이라는 데이터 *(Final Records)*

## 부록
- A. 재현 안내: R, R Markdown, 구글 시트 연결
- B. 한 학기 설문/실험 운영 매뉴얼
- C. 코드와 데이터 구조 (한 폼·시간구간 분석 설계 포함)

### 메모 (집필 시 고려)
- 각 장은 〈실험의 목적 → 어떻게 했나 → 학생들의 실제 응답(표·그림) → 무엇을 배웠나〉
  의 동일한 리듬으로 쓰면 통일감이 생긴다. (지금 Rmd들이 이미 이 구조)
- 독자층을 정하면 코드 분량이 갈린다:
  - 일반 교양 독자 → 코드는 부록/온라인으로, 본문은 이야기와 그림 중심
  - 교수자·학생 → bookdown으로 코드와 결과를 함께 (살아있는 교재)
- 가장 강한 차별점: *교과서의 사례가 아니라, 내 강의실에서 나온 실제 숫자와 반응.*
